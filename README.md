# Agenda de Contatos em Python

Um sistema e interativo de gerenciamento de contatos desenvolvido em Python, este projeto roda direto no terminal e permite salvar, editar, deletar, favoritar e mostrar contatos e contatos favoritados

* **Adicionar Contato:** Insere um novo nome e número na lista de contatos.
* **Editar contato:** Permite editar um nome ou número do contato(Caso não queira editar só clicar a tecla ENTER).
* **Deletar Contato:** Remove o contato que o usuário selecionar da lista.
* **Favoritar:** Favorita um contato e adiciona na lista de contatos favoritados.
* **Mostrar contatos:** Mostra todos contatos adicionados na lista de contatos.
* **Mostrar contatos favoritados:** Mostra todos contatos que o usuário adicionou como favorito.
